# 💊 Supplement Bot - Персональный консультант по БАДам

Telegram бот для подбора биологически активных добавок на основе персонального опросника с системой напоминаний и монетизацией.

## 🚀 Возможности

### Для пользователей
- **📋 Персональный опросник** (8 вопросов - Free, 17+ вопросов - Premium)
- **💊 Умные рекомендации** БАДов на основе ответов
- **⏰ Система напоминаний** о приеме добавок
- **📊 Статистика** соблюдения режима приема
- **💎 Premium подписка** с расширенными возможностями

### Для разработчика
- **🔧 Модульная архитектура** на Telegraf + SQLite
- **💳 Интеграция с ЮКассой** для платежей
- **📱 Адаптивный UX** с прогресс-барами и уведомлениями
- **🔍 Тестовые команды** для отладки

## 🔧 Команды для разработки

### Тестовые команды в боте

#### 📊 Управление напоминаниями
`/myreminders`      Показать все активные напоминания пользователя
`/reminderstatus`   Статус системы напоминаний и активность
`/reminderstats`    Статистика приема добавок за 30 дней
`/checkhistory`     Детальная история приема за 7 дней
`/myhistory`        Краткая история приема (альтернативная команда)

#### 💎 Управление подписками
`/debugsub`	          Детальная информация о подписке пользователя
`/activatepremium`	  Активировать Premium подписку вручную (на 1 месяц)
`/checkmenu	`         Диагностика меню и доступных функций

#### 🗃 Управление данными
`/clearmydata`	Полная очистка всех данных пользователя
`/backupstatus`	Статус системы бэкапов
`/backupnow`	  Создать бэкап вручную

#### 📈 Аналитика (только для администратора)
`/analytics`	  Панель аналитики за 30 дней
`/surveystats`	Детальная аналитика опросника
`/dailyreport`	Принудительная генерация ежедневного отчета


## 💾 База данных

### Структура таблиц
- **users** - данные пользователей
- **subscriptions** - подписки
- **payments** - платежи
- **reminders** - напоминания
- **intake_history** - история приема
- **analytics** - аналитика

### Резервное копирование
Бэкапы создаются автоматически каждые 6 часов в папку `backups/`.


## 🔐 Настройка продакшена

### 1. Подготовка сервера
```bash
# Установка PM2
npm install -g pm2

# Настройка автостарта
pm2 startup
pm2 save
```

### 2. Production окружение
Создайте `.env.production`:
```env
BOT_TOKEN=production_bot_token
NODE_ENV=production
YOOKASSA_SHOP_ID=production_shop_id
YOOKASSA_SECRET_KEY=production_secret_key
```

### 3. Деплой
```bash
# Через PM2
pm2 start ecosystem.config.js --env production

# Или через npm
npm run production
```

## 🐛 Поиск и устранение неисправностей

### common проблемы
1. **Напоминания не приходят**
   ```bash
   /forcereminders  # Принудительная отправка
   /reminderstatus  # Проверить статус
   ```

2. **Ошибки базы данных**
   ```bash
   /clearmydata     # Очистить данные
   npm run check-db # Проверить структуру БД
   ```

3. **Бот не запускается**
   ```bash
   npm run stop && npm start  # Перезапуск
   pm2 delete supplement-bot && pm2 start  # Через PM2
   ```

### Логирование
Уровни логирования настраиваются через `LOG_LEVEL` в .env:
- `error` - только ошибки
- `info` - основная информация
- `debug` - детальное логирование
